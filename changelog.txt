Changelog for twentyfifteen-more
====================


* v2.7.35 - 2026-10-16
 * - Added UTM Compartilhamento meta box to post editor for easy UTM parameter insertion.
 *   Includes pre-filled defaults (source: youtube, medium: social, campaign: post title) and a ready-to-copy URL.
 * - Updated functions.php with ni_utm_share_meta_box() and related functions.

* v2.7.36 - 2026-10-16
 * - Fixed syntax error in functions.php caused by incorrect UTM meta box addition (unclosed PHP tag).
 * - Re-added UTM Compartilhamento meta box with proper PHP syntax.
 * - Ensured no stray HTML or PHP tags that could cause parsing errors.

* v2.7.37 - 2026-10-16
 * - Added code to disable update notifications for default WordPress themes.
 * - Prevents update prompts for bundled themes (twentyfifteen, twentysixteen, etc.) that are not in use.
 * - Added function ni_hide_default_theme_updates() and hooked to site_transient_update_themes.

* v2.7.38 - 2026-10-16
 * - Updated theme update hiding to include newer default themes:
 *   Added twenty-twenty-three, twenty-twenty-four, twenty-twenty-five to the list.
 * - Function ni_hide_default_theme_updates now hides updates for all default themes up to twenty-twenty-five.

* v2.7.39 - 2026-10-16
 * - Fixed syntax error in functions.php: escaped single quotes in theme list.
 * - Updated theme update hiding to include newer default themes up to twenty-twenty-five.
 * - Bumped version to 2.7.39.

* v2.7.40 - 2026-10-16
 * - Fixed syntax error: removed escaped single quotes in theme list.
 * - Ensured proper quoting in ni_hide_default_theme_updates function.
 * - Verified braces count and PHP tags.

* v2.7.41 - 2026-10-17
 * - Meta box "UTM Compartilhamento" v2: Fonte e Midia agora sao dropdowns
 *   (youtube/tiktok/twitter/telegram/facebook e social/video/chat/bio),
 *   eliminando typos que fragmentam dados no GA4.
 * - Campanha (utm_campaign) pre-preenchida automaticamente com o slug do post.
 * - Novo botao "Copiar link com UTM" (clipboard via navigator.clipboard com
 *   fallback execCommand); campo readonly mostra a URL final em tempo real.
 * - Normalizacao automatica da campanha (minusculas, sem espacos/acentos).
 * - Lintado com php -l (PHP 8.3) antes do deploy.
